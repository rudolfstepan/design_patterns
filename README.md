# Design Patterns in C#

Dies ist eine Sammlung von Software-Design-Patterns, umgesetzt in C# und beschrieben im Markdown-Format.

## Inhalt

Die Sammlung enthält klassische Entwurfsmuster sowie ergänzende moderne Prinzipien wie **Dependency Injection**, das ursprünglich nicht Teil der GoF-Muster war.
